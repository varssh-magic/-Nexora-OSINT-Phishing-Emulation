
# Reconnaissance and OSINT

## Objective
Perform domain reconnaissance and identify the available assets associated with the fictional Nexora Technologies lab.

## Tools
- SpiderFoot
- theHarvester
- Maltego

## Target
nexora.test

## Activities
1. Domain reconnaissance.
2. Subdomain enumeration.
3. DNS information collection.
4. Employee-role mapping using synthetic identities.
5. Relationship visualization using Maltego.

## Results
Actual tool outputs are stored in this directory.

## Limitations
The .test domain is reserved for testing and is not a publicly registered organization domain. Public OSINT services may therefore return no results. Any manually created lab records are identified as synthetic.
